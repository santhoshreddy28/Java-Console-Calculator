# 🧮 Secure Java Calculator

A lightweight command-line calculator developed in Java that performs fundamental arithmetic operations while demonstrating core programming concepts such as methods, loops, conditionals, and user input handling.

---

## 🛡️ Project Overview

This project simulates a basic calculator application that allows users to perform mathematical calculations through a menu-driven interface.

The application demonstrates foundational software development principles including:

* Method Design
* Control Flow
* User Input Processing
* Error Handling
* Looping Mechanisms

---

## 🚀 Features

### ➕ Addition

Perform addition of two numbers.

### ➖ Subtraction

Calculate the difference between numbers.

### ✖️ Multiplication

Multiply numeric values efficiently.

### ➗ Division

Perform division with divide-by-zero protection.

### 🔄 Continuous Operations

Execute multiple calculations without restarting the application.
