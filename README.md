# Java Console Calculator

## Objective
A simple calculator built using Java Console I/O.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Divide-by-zero handling
- Menu-driven interface
- Loop for multiple calculations

## Technologies Used
- Java
- Scanner Class
- Methods
- Loops
- Switch Case

## How to Run

1. Compile:
   javac Calculator.java

2. Run:
   java Calculator
